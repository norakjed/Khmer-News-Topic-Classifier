Sections deliberately NOT used: national/international (mixed topics), advertising/promote content, flood, covid19, specialedition, scholar, weird, hong-suy (fortune telling).

Rules:
- Drop a class if it has fewer than ~300 articles; each class from at least 2 sites.
- Society/Health merges three different site sections; spot-check about 100 articles and split or drop it if inconsistent.
- Dedupe by URL and by normalised title (sites may repost the same story).
